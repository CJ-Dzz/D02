# 方舟电台 · BUILD 6.9

整体配乐为项目内创作的《熄灯后的春天》，由 `audio-engine.js` 的和声、旋律和乐器实现。D 大调、4/4、92 BPM、32 小节，默认一轮约 83.48 秒。温暖键盘、拨弦、钟音、铺底、低音与轻电子鼓贯穿整个游戏；菜单、白昼、夜晚、休整、奖励关、Boss、暂停与结算使用同一主题的不同声部配置，保持连续时间线。

技能语音由本机 Windows SAPI 中文语音合成并录制为 22050 Hz、16 位、单声道 WAV。文件已随项目提供，玩家不需要本机语音服务或联网。它们属于合成语音，没有使用真人配音或模仿特定演员。

| 文件前缀 | 合成声音与语气 | 角色台词风格 |
| --- | --- | --- |
| `sprout` | Microsoft Huihui Desktop，略高音高、稍快语速 | 轻快、鼓励，一起播种与期待明天 |
| `beat` | Microsoft Yaoyao，更高音高、更快语速 | 俏皮、有节拍感，让末日热闹起来 |
| `mochi` | Microsoft Huihui，较低音高、较慢语速 | 舒缓、安抚，强调守护与陪伴 |

每人两句，成功释放技能时轮换；文本和时长随 `character-voices.js` 保存。运行 `python scripts/build-voices.py` 可从本目录 WAV 重新打包为数据模块，公开构建会再将该模块内联进 HTML。

播放技能语音时配乐暂时降低至设定音量的 36%，语音后恢复；新播报替换旧播报，不排队。音乐、音效、语音可以独立调节，关闭语音仍保留字幕。音乐和语音在首次用户手势后启动，隐藏页面时暂停音频。
