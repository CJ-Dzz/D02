# 荒穗计划：AI 娘最后一块田

一款可以直接在浏览器中游玩的萌系末日种田战斗 Roguelite。世界熄灭后，玩家与小芽、霹雳或奶泡中的一名 AI 娘共同经营最后的农区，在五日远征中寻找种子库。

当前版本 **BUILD 7.0 · 扎根的世界**：地图实体底座统一参与碰撞，走路、冲刺、击退和地面敌人不能穿过岩石、树干与建筑；普通弹丸被实体遮挡。场景补充接地阴影、风化材质和结构细节。加入固定在线入口、离线包和局外存档导入导出；延续统一配乐和角色语音。美术规范见 [`assets/ART_DIRECTION.md`](./assets/ART_DIRECTION.md)。

## 开始游玩

[固定在线入口](https://cj-dzz.github.io/D02/wildroot/) · [下载离线版](https://cj-dzz.github.io/D02/wildroot/Wildroot-Offline.zip)

在线入口随发布分支更新，无需每轮替换提交编号，也不经过 HTMLPreview 或 chatgpt.site。网络托管无法保证永远可用；下载离线包、解压并双击其中的 `index.html`，即使网站停用也能继续玩下载时的版本。

从源码游玩时，双击打开 [`index.html`](./index.html)，先选 AI 娘、确认后选武器，再点击“开始远征”。游戏不需要安装依赖，也不需要联网。复制源码时保留 `assets/` 文件夹、三个样式文件及七个 JavaScript 文件；公开版和离线包会内联全部素材与语音。

主菜单底部可以导出和导入 JSON 存档，包含芽晶、实验室、图鉴、成就和历史统计。不同域名、浏览器和文件路径的本地存档可能相互独立，迁移前请导出备份。当前只备份局外进度，暂不支持未结束远征的中途续玩。

推荐使用 Chrome 或 Edge，并将窗口保持在至少 1280×720。首次点击或按键后开始播放音乐。右上角音符可单独调节音乐、音效与技能语音，或全部静音；静音时仍保留技能字幕。

## 操作

准备页：`← / →` 切换当前人物或武器，确认按钮或 `Enter` 进入下一步；`Esc` 可从武器页退回人物页。完整技能点击“技能与被动详情”，图鉴与实验室位于右上角图标。

| 按键 | 动作 |
| --- | --- |
| `WASD` | 移动 |
| 鼠标 | 瞄准，按住左键射击或挥砍 |
| `1`—`8` / 鼠标滚轮 | 数字键直选对应作物；滚轮在本局已解锁种子与主动道具间切换 |
| `E` | 在相邻田块播种、浇水、收获、开启遗物箱、互动野外设施或使用开荒铲 |
| `Q` | 使用当前 AI 娘的专属主动技能 |
| `Space` | 冲刺，期间短暂无敌 |
| `F` | 在无限时休整轮主动开始下一波 |
| `P` | 暂停 |

## 一轮里要做什么

- 开局选择的 AI 娘有全身大立绘与独立面部表情：小芽好奇张口笑、霹雳挑眉眨眼、奶泡弯眼浅笑；角色卡和 HUD 使用对应头像。
- 五种武器在选择界面展示动态结构预览，局内会握持瞄准，并表现枪机、泵动、线圈、悬浮核心或镰刃挥砍。
- 商店每次从 21 件货物中抽选四件；新增雨水罐、便当、种子盲盒、花蜜、堆肥、保水种壳、丰收护符、罗盘和握把。三类补给每天限购一次，永久器件仍每局限购一次。
- 每天在五个候选位置按 72% 概率尝试生成、最多四处野外设施：雨水桶、堆肥机、种子柜、记忆终端、工作台和授粉风铃。小地图菱形标记；靠近按 `E`，先查看消耗。每种当天最多一处，用过不能重复领取。

- 击败害兽会将经验、水和通用生物质向四周散射；怪物不再直接掉落具体种子。
- 单局固定 15 波，每日 3 波；第 2 波结束后进入无限时无怪休整，玩家可从容采购、切换种子、浇水和播种，准备好后按 `F` 开始当日终局。
- 普通计时波从 22 秒开始，每波增加 0.75 秒；奖励波从 17 秒开始，每波增加 0.45 秒。后期波次给经营和转场留出更多空间，Boss 仍以击败为结束条件。
- 第 3、8 波是低压奖励关：敌群更少、没有弹幕怪、不会攻击作物，完成后获得治疗、水、生物质与全部已解锁种子。第 6、12、15 波是首领关。
- 开局固定解锁火爆辣椒、向日葵和豌豆炮；其余五种种子会作为随机蓝图随休整商店一起刷新。支付生物质解锁后，本局余下时间都能种植，并立即把对应插件、杂交和组合配方加入选择池。
- 播种后的土地自带少量湿度；作物缺水后停止生长，需要靠近并按 `E` 浇水。
- 作物只有夜晚会受伤；普通怪物中只有啃根虫、野猪、掠种贼和极少数“腐田”精英会主动攻击田块。
- 地图分布着避难所菜园、破碎温室、旧城天台与陨坑湿地四个农区；它们拥有不同的生长速度、产量和防御特性。
- 同一农区混种越丰富，成熟时越容易产生异变作物。异变作物拥有强化光环，收获收益与技能效果翻倍。
- 相邻特定作物可以培育九种杂交作物，例如磁轨豌豆、日光堡垒、爆燃玉米和冰霜爆米花；它们拥有双果实菱形标识，收获后还会把对应能力写入本局人物属性。
- 八种作物遵循直觉功能：辣椒横扫整行、向日葵产阳光、豌豆炮自动射击、磁力菇吸走资源与敌弹、寒冰菇全屏冻结、模仿菇复制邻近作物、铁壳坚果分摊田地伤害、玉米投手进行范围轰炸。
- 远程火力、无人机、叶刃和扎根能力都需要成熟作物或“丰收动能”启动；战斗升级提供农战联动，收获才会换来射速、弹量、追踪和防护等战斗增益。
- 每次收获获得短时丰收动能。第一日收获经济被压低，之后逐日恢复，前期需要先经营阵地，再把农田转化成战斗力。
- 累计收获与自然杂交可永久解锁四张组合卡。休整轮购买卡后，可把两株相邻作物合成双联豆炮、聚光向日塔、冷热反应炉或玉米加农炮；组合植株可继续收获，并提供有上限的本局永久属性。
- 脉冲滴灌器会缓慢为单株补水且仍消耗水；单格播种机会消耗当前种子、只在玩家附近播种且不会代替收获。
- 普通等级提供种植、农战和当前武器专属插件；等级达到 3、6、9……时会改为攻击、护甲、移速、闪避四选三的通用属性节点，单次增幅已经下调为攻击 +7%、受伤 -5%、移速 +5% 或闪避 +3.5%。每日终局遗物箱继续提供稀有底层参数。
- 开局可直接选择月芽收割镰作为第五把武器；近战不再占用天赋，远程插件不会进入镰刀升级池，镰刀也拥有独立专精与生命收割融合。
- 五把武器各有独特规则：步枪每第 6 发过载，霰弹贴脸孢爆，轨道枪贯穿后增伤，法杖命中分裂芽弹，镰刀宽幅击退并由作物改变刀刃。
- 九套融合配方会带来玩法质变，包括生命收割回路和固定丰收炮台两条新路线。
- 前四天会随机轮换断桥田、移动温室、夜间停电区和可争夺灌溉站，第五天同时启用两种规则。
- 远征中会低频出现生物质雨、生长季风、害兽团建与磁极反转，事件间隔约 72—100 秒；强制连续播种与播种倒计时已移除。
- 随机事件只有在当前波剩余时间足以完整播放时才会触发；已开始的事件会先自然收尾，再结算波次，不会被倒计时中途截断。
- 休整时作物湿度、生长、成熟被动和自动农具全部冻结；玩家仍可采购、手动播种、浇水、收获和调整阵地，不会利用无限休整刷取被动收益。
- 休整轮的商店 NPC 会出售开荒铲和 11 种随机货物，每件都有独立彩色器件图案。直接人物属性货物大幅提价并收敛增幅，新加入慢释肥、冷却液、种子袋和田地修补箱。刷新价格在整局中按 2、4、6……递增；开荒铲有 5 点耐久，可在安全地面开垦 5 块独立新田，开垦不会再拖动原农区或商人位置。
- 八种种子补给按强度分级定价：向日葵 2，辣椒、豌豆炮与坚果 3，磁力菇、寒冰菇与玉米 4，模仿菇 5；每次仍购买 2 颗，蓝图价也会随种子等级上浮。
- 怪物上限按经过时间的对数与平方根函数平滑上升，弹幕怪在第五日普通刷新池中的权重约为六分之一。断桥河道内生成的经验会自动落到最近岸边。
- 普通敌人只生成一份高价值经验；水和生物质的出现概率降低，但单份价值提高到 2。附近同类掉落会在 82 像素内自动合并并显示 `×N`，Boss 奖励也压缩为少量大额掉落。
- 三名 AI 娘拥有完全不同的战斗外形和专属技能：小芽催熟并命令作物齐射，霹雳发动范围雷击与超频，奶泡生成护盾并灌溉全图。
- 每局从苔原回潮、锈沙花季与紫孢低地三种地貌基调中随机一种；温室骨架、旧城水箱与雷达、湿地水洼芦苇、避难所风机和太阳能板让四个区域的远景更容易辨认。人物增加背包、关节与状态灯，普通怪物增加触角、甲片、表情和类型专属动态细节。
- 每名 AI 娘拥有只能由自己取得的专属插件和个人胜利结局；开局可选择步枪、霰弹枪、轨道枪、共生法杖或月芽收割镰。
- 休整商店可通过“上拉收起”缩成顶部短条，露出角色和农田；再次展开后可继续购买与刷新。
- Boss 会从两种变体中随机出现，并在 66% 与 33% 血量进入狂暴阶段；普通敌人也可能获得狂暴、装甲、分裂、虹吸或腐田词缀。
- 主页面的末日图鉴记录作物、杂交、组合植株、融合、武器、怪物、精英和 Boss 变体；组合卡会显示成就解锁条件，首次发现会奖励芽晶。
- 本轮插件栏固定每页显示 8 项，通过左右箭头分页；武器、遗物、商店道具、通用属性、组合卡、插件和融合不再无限向两侧挤压。
- 掠种贼会偷走成熟作物，修复者会为害兽群回血，故障兽死亡后会分裂，优先级判断成为战斗的一部分。
- 连续击杀只提高得分与掉落节奏；丰收动能和少量超频主要来自收获，推动玩家用作物换取强势窗口。生存日志与地形通知会自动关闭，冲刺和角色技能拥有独立的“就绪”高亮。
- 每轮结束都会获得“芽晶”。局外实验室拥有战斗、育种、备份、雷达、记忆与陪伴六条永久成长线，每条可升至 8 级；结算或暂停时都能返回主页面投资。

可调参数集中在 [`game-config.js`](./game-config.js)，包括波次基础时长与逐波增量、掉落合并与价值、敌人密度与刷新倍率、精英概率、事件间隔、升级属性、选择权重、育种概率、各类种子价格、商店库存数、设施每日概率与类型权重，以及插件分页数量。完整的系统逻辑、作物、流派、敌人、Boss、五日关卡和数值规则见 [`GAME_DESIGN_DOCUMENT.md`](./GAME_DESIGN_DOCUMENT.md)。玩法取舍和参考作品的设计原则记录在 [`DESIGN.md`](./DESIGN.md)。

发布独立页面：`python scripts/build-public.py <输出HTML路径>`。构建会内联四张透明图集、配乐引擎与六句技能语音，保留原始 alpha，不增加运行时依赖。

生成离线包：`python scripts/build-offline.py <独立HTML路径> <输出ZIP路径>`。

碰撞与地图连通测试：`node scripts/physics-review.cjs`。实际游戏运行与 Canvas 渲染回归：`node scripts/runtime-review.cjs`，测试环境另需 `linkedom` 与 `@napi-rs/canvas`，运行游戏本身不需要这些依赖。Steam 发布差距与验收目标见 [`STEAM_RELEASE_PLAN.md`](./STEAM_RELEASE_PLAN.md)。
