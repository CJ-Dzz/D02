# 荒穗计划：AI 娘最后一块田

一款可以直接在浏览器中游玩的萌系末日种田战斗 Roguelite。世界熄灭后，玩家与小芽、霹雳或奶泡中的一名 AI 娘共同经营最后的农区，在五日远征中寻找种子库。

## 开始游玩

双击打开 [`index.html`](./index.html)，然后点击“开始末日生存”。游戏不需要安装依赖，也不需要联网。

推荐使用 Chrome 或 Edge，并将窗口保持在至少 1280×720。首次点击开始后，浏览器才会允许游戏播放程序化音效。

## 操作

| 按键 | 动作 |
| --- | --- |
| `WASD` | 移动 |
| 鼠标 | 瞄准，按住左键射击或挥砍 |
| `1`—`6` | 选择火爆辣椒、向日葵、豌豆炮、磁力菇、寒冰菇或模仿菇 |
| `E` | 在相邻田块播种、浇水、收获或开启遗物箱 |
| `Q` | 使用当前 AI 娘的专属主动技能 |
| `Space` | 冲刺，期间短暂无敌 |
| `P` | 暂停 |

## 一轮里要做什么

- 击败害兽会将经验、水和通用生物质向四周散射；怪物不再直接掉落具体种子。
- 每个白昼后都有 24 秒无怪休整轮。玩家用生物质购买种子、浇水、播种并重新布置阵地。
- 开局从六种作物中选择三种携带；未携带的种子本轮不能使用，种子商店也只出售这三类。
- 播种后的土地自带少量湿度；作物缺水后停止生长，需要靠近并按 `E` 浇水。
- 作物只有夜晚会受伤；普通怪物中只有啃根虫、野猪、掠种贼和极少数“腐田”精英会主动攻击田块。
- 地图分布着避难所菜园、破碎温室、旧城天台与陨坑湿地四个农区；它们拥有不同的生长速度、产量和防御特性。
- 同一农区混种越丰富，成熟时越容易产生异变作物。异变作物拥有强化光环，收获收益与技能效果翻倍。
- 相邻特定作物可以培育六种杂交作物，例如磁轨豌豆、蒸汽冰椒和镜霜双生菇。
- 六种作物遵循直觉功能：辣椒横扫整行、向日葵产阳光、豌豆炮自动射击、磁力菇吸走资源与敌弹、寒冰菇全屏冻结、模仿菇复制邻近作物。
- 远程火力、无人机、叶刃和扎根能力都需要成熟作物或“丰收动能”启动；战斗升级提供农战联动，收获才会换来射速、弹量、追踪和防护等战斗增益。
- 每次收获获得短时丰收动能。第一日收获经济被压低，之后逐日恢复，前期需要先经营阵地，再把农田转化成战斗力。
- 累计收获与自然杂交可永久解锁三张组合卡。休整轮购买卡后，可把两株相邻作物合成双联豆炮、聚光向日塔或冷热反应炉。
- 脉冲滴灌器会缓慢为单株补水且仍消耗水；单格播种机会消耗当前种子、只在玩家附近播种且不会代替收获。
- 普通插件只塑造流派与联动；每夜必掉的关键遗物箱才提供最大生命、基础攻击、技能冷却等本轮永久属性。
- 收割镰刀会把主攻击替换成更快、更宽、更强的近战扇形挥砍，并由不同作物赋予刀程、爆破、暴击、冻结或回声斩；扎根协议只有连接农田后才能蓄力。
- 九套融合配方会带来玩法质变，包括生命收割回路和固定丰收炮台两条新路线。
- 前四天会随机轮换断桥田、移动温室、夜间停电区和可争夺灌溉站，第五天同时启用两种规则。
- 远征中会随机出现生物质雨、种子狂暴、生长季风、害兽团建与磁极反转。种子狂暴持续 30 秒，每 3 秒内必须播种，否则受到不断递增的伤害。
- 三名 AI 娘拥有完全不同的战斗外形和专属技能：小芽催熟并命令作物齐射，霹雳发动范围雷击与超频，奶泡生成护盾并灌溉全图。
- 每名 AI 娘拥有只能由自己取得的专属插件和个人胜利结局；开局还可选择步枪、霰弹枪、轨道枪或共生法杖。
- Boss 会从两种变体中随机出现，并在 66% 与 33% 血量进入狂暴阶段；普通敌人也可能获得狂暴、装甲、分裂、虹吸或腐田词缀。
- 主页面的末日图鉴记录作物、杂交、组合植株、融合、武器、怪物、精英和 Boss 变体；组合卡会显示成就解锁条件，首次发现会奖励芽晶。
- 掠种贼会偷走成熟作物，修复者会为害兽群回血，故障兽死亡后会分裂，优先级判断成为战斗的一部分。
- 连续击杀只提高得分与掉落节奏；丰收动能和少量超频主要来自收获，推动玩家用作物换取强势窗口。
- 每轮结束都会获得“芽晶”。局外实验室拥有战斗、育种、备份、雷达、记忆与陪伴六条永久成长线，每条可升至 8 级；结算或暂停时都能返回主页面投资。
